# V1.25.10 - Tests Windows en affichage compact

Objectif : rendre les tests initiaux plus lisibles pour l'utilisateur.

## Comportement

- `LANCER_TESTS.cmd` appelle `scripts\run_tests_compact.py`.
- La fenetre affiche une progression courte : `Statut tests : N / X`.
- Les details ne sont affiches que pour les erreurs ou echecs.
- Le bilan final reste visible.

## Tests attendus
