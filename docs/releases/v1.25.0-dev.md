# V1.25.0-dev - Preparation GitHub

## Objectif

Creer une base de depot GitHub pour Gestion Club en s'inspirant de l'organisation Neo Toolkit, sans modifier le comportement metier valide en V1.24.5.

## Changements

- Creation d'une arborescence de developpement :
  - `client/`
  - `server/`
  - `tests/`
  - `docs/`
  - `scripts/windows/`
  - `vendor/`
- Adaptation du serveur pour servir les fichiers statiques depuis `client/`.
- Adaptation des scripts Windows pour fonctionner depuis la nouvelle racine.
- Adaptation du chemin du worker PDF vers `vendor/`.
- Ajout de documents racine : `README.md`, `ARCHITECTURE.md`, `BUILD.md`, `TESTING.md`, `ROADMAP.md`, `DEVELOPMENT_METHOD.md`.
- Ajout d'un `.gitignore` protegeant `data/`, `releases/`, les bases SQLite et les fichiers temporaires.

## Validation

Commande executee :

```bash
./scripts/run_tests.sh
```

Resultat :

```text
Ran 73 tests in 8.610s
OK
```

## Suite logique

La prochaine etape peut etre la creation du depot distant GitHub puis le push de cette base. Ensuite, la V1.25.1 pourra raccorder le client complet a la revision serveur active.
