# V1.25.1 - Ouverture calme du client complet

## Objectif

Commencer le raccordement client-serveur general sans modifier brutalement le fonctionnement historique du gros client HTML.

## Livré

- Route serveur protegee `/gestion`.
- API `/api/gestion/bootstrap` avec utilisateur, role, mode serveur et derniere revision.
- Bandeau visible dans le client complet servi par le serveur.
- Bouton d'acces depuis l'administration serveur.
- Validation du client monolithique avec une CSP limitee a cette route, car le HTML historique contient encore des scripts inline.

## Limite volontaire

Les ecritures internes du client complet restent encore celles du client historique. La prochaine etape doit raccorder l'enregistrement complet au serveur par une action explicite.

## Tests ajoutes

- `/gestion` refuse les acces anonymes.
- `/gestion` sert le client complet a une session connectee.
- `/api/gestion/bootstrap` renvoie la derniere revision.
