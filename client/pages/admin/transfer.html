Tests regroupés — données fictives

Ce contrôle vérifie les règles de comparaison. Il ne modifie pas la base et ne remplace pas un essai de navigation ou de restauration dans Brave.

Sélectionnez une sauvegarde complète Gestion Club pour comparer son contenu avec la base actuelle. La lecture ne remplace aucune donnée.

Option : utiliser une sauvegarde de référence commune

Choisissez d’abord une sauvegarde prise avant les modifications des deux bases, puis le fichier à comparer ci-dessous. Si vous ne disposez pas de cette référence, gardez la comparaison habituelle à deux bases.

Sans référence : comparaison entre deux bases.

L’application ne peut pas prouver que cette sauvegarde est l’ancêtre des deux bases. « À arbitrer » signifie que la fiche entière a changé différemment des deux côtés, relativement à votre référence.

Lire les différences

« Différentes » désigne les fiches portant le même identifiant interne dont le contenu a changé. Deux identifiants différents ne sont pas rapprochés automatiquement, même si les noms se ressemblent.

Sans une version de référence commune, ce contrôle ne peut pas déterminer quelle valeur est la plus récente. Une fiche absente du fichier n’est jamais considérée comme une demande de suppression.

Le bilan exporté contient les comptes de différences, les états de contrôle et les libellés prédéfinis des champs concernés. Il ne contient pas les noms, coordonnées ou identifiants individuels et ne permet pas de restaurer la base.

Pour transférer la base entière après vérification, utilisez la sauvegarde complète originale dans Données & sauvegarde. Cette opération remplace la base ; elle ne fusionne pas les modifications de deux postes.
