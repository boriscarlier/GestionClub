# V1.25.7 - Mise a jour Windows en un geste

Objectif : appliquer une nouvelle version vers le dossier stable du club, lancer les tests, puis demarrer le serveur sans ressaisir le chemin.

## Comportement

- Dossier cible par defaut : `D:\GESTION_CLUB_GestionClub`.
- Le dossier `data` de la cible est conserve.
- `LANCER_TESTS.cmd` est execute apres la copie.
- `DEMARRER_SERVEUR.cmd` est execute seulement si les tests passent.

## Marche a suivre utilisateur

1. Decompresser le nouveau zip dans un dossier temporaire.
2. Double-cliquer sur `METTRE_A_JOUR.cmd`.
3. Laisser les tests se terminer.
4. Si les tests passent, le serveur demarre automatiquement.

Pour utiliser un autre dossier exceptionnellement, lancer :

```bat
METTRE_A_JOUR.cmd "E:\Autre_Dossier_GestionClub"
```
