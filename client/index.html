Le serveur du club

Sauvegardes versionnées et veille des sources publiques.

Les sauvegardes déposées sont conservées dans le dossier data de ce paquet. Les écrans métier de Gestion Club continuent à utiliser leur base dans Brave. Aucun transfert automatique entre les deux.

Connexion au serveur

Au premier lancement, créez votre compte dans la fenêtre du lanceur. Les comptes du HTML ne donnent pas accès au serveur.

Révision enregistrée

Préparer un dépôt

Choisissez une sauvegarde complète JSON exportée depuis Gestion Club. Chaque dépôt crée une nouvelle révision ; les précédentes restent consultables. Les comptes contenus dans la sauvegarde restent des données et n’accordent aucun droit serveur.

Historique des 100 dernières révisions

Téléchargez une ancienne révision pour l’examiner dans Gestion Club. Le téléchargement ne la réactive pas.

Veille du club

Les liens repérés restent consultables ici. Classez-les « À lire », « Lu », « À traiter » ou « Archivé ».

La première collecte établit un point de départ : un lien nouvellement repéré peut être ancien. Couverture partielle : titres, résumés de flux et liens publics ; PDF accessibles dans le bloc Documents PDF. Les thèmes sont attribués par mots-clés et restent à vérifier.

Sources et collecte

Heures de La Réunion. La mairie est prévue tous les 7 jours ; la Ligue est manuelle au départ. La planification fonctionne seulement avec le PC éveillé et le serveur lancé. Un contrôle échu reprend après redémarrage.

Documents PDF — joueurs, mentions et dates

Déposez un PDF pour relever les joueurs du club dans les tableaux compatibles, les mentions du club, les convocations et les dates avec leur numéro de page. Texte extractible uniquement : pas d’OCR ni de connexion Gmail.

Les originaux et les textes peuvent contenir des données personnelles. Ils sont consultables par les comptes serveur autorisés. La copie du dossier data, serveur arrêté, sauvegarde ces documents ; l’export JSON des liens ne les inclut pas.

Importer une page Ligue enregistrée dans Brave

Sur une page publique de la Ligue : Ctrl+S → HTML uniquement. Choisissez le fichier ici, examinez les titres puis confirmez. L’import n’effectue aucune connexion au site.
