# V1.25.2 - Enregistrement explicite depuis le client complet

## Objectif

Commencer le raccordement reel entre le client complet et la base serveur sans modifier les modules metier internes un par un.

## Livré

- V1.25.1 consideree stable.
- Bandeau serveur du client complet passe en V1.25.2.
- Action volontaire "Enregistrer sur serveur" depuis `/gestion`.
- Telechargement de la derniere revision serveur depuis le client complet.
- Controle de session, CSRF, revision attendue et confirmation serveur avant creation d'une revision.
- Le client complet exporte maintenant ses sauvegardes sous `V1.25.2`.

## Limite volontaire

Les ecritures fines des modules metier restent encore dans le fonctionnement historique du client. Le prochain vrai choix consiste a decider entre :

- garder une sauvegarde complete explicite comme unite principale d'ecriture serveur ;
- ou raccorder progressivement chaque module a des API specialisees.

## Tests ajoutes

- Presence des actions serveur dans `/gestion`.
- Depot d'une sauvegarde `V1.25.2` accepte par le serveur.
