# V1.25.6 - Installation Windows simplifiee

Objectif : tester les nouvelles versions sans recreer un serveur et sans recopier la base `data`.

## Ajouts

- `DEMARRER_SERVEUR.cmd` a la racine du dossier.
- `LANCER_TESTS.cmd` a la racine du dossier.
- `METTRE_A_JOUR.cmd` pour recopier les fichiers programme vers un dossier stable en excluant `data`.
- Variables optionnelles `GESTION_CLUB_DATA_PATH` et `GESTION_CLUB_DATA_DIR`.

## Marche a suivre utilisateur

1. Garder un dossier stable, par exemple `D:\GestionClub`.
2. Lancer le serveur avec `D:\GestionClub\DEMARRER_SERVEUR.cmd`.
3. Pour une nouvelle version, decompresser le zip dans un dossier temporaire.
4. Depuis ce dossier temporaire, lancer `METTRE_A_JOUR.cmd`.
5. Indiquer `D:\GestionClub` comme cible.
6. Relancer `D:\GestionClub\DEMARRER_SERVEUR.cmd`.

Le dossier `data` de la cible n'est pas remplace par la mise a jour.

## Tests attendus

- `LANCER_TESTS.cmd` doit terminer sans echec.
- Le serveur doit afficher le chemin de la base utilisee.
- Apres mise a jour, la revision serveur et les donnees du club doivent toujours etre presentes.
