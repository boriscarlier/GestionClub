# V1.25.9 - Garde-fou anti double demarrage Windows

Objectif : eviter de lancer deux serveurs Gestion Club en meme temps sur le meme ordinateur.

## Comportement

- Avant de demarrer Python, `DEMARRER_SERVEUR.cmd` teste `127.0.0.1:8765`.
- Si un serveur repond deja, le script ouvre `http://127.0.0.1:8765/`.
- Dans ce cas, aucune nouvelle instance Python n'est lancee.
- `METTRE_A_JOUR.cmd` beneficie du meme garde-fou, car il appelle `DEMARRER_SERVEUR.cmd` apres les tests.

## Tests attendus

- La suite automatisee doit passer.
- Lancer `DEMARRER_SERVEUR.cmd` une premiere fois : le serveur demarre.
- Relancer `DEMARRER_SERVEUR.cmd` pendant que le serveur tourne : la page existante s'ouvre et aucun deuxieme serveur n'est cree.
