# V1.25.5 - Lecture des equipes depuis l'API serveur

## Objectif

Continuer la migration module par module vers SQL/API avec le module Equipes, apres le module Licencies.

## Ajouts

- Table SQL `teams` creee au demarrage.
- Synchronisation des equipes lors de chaque depot de sauvegarde complete.
- Reconstruction des equipes depuis la derniere revision lors d'une migration douce.
- API lecture :
  - `/api/state/teams`
  - `/api/state/teams/{id}`
- Compteur `teams` ajoute a `/api/state/summary`.
- Ecran Equipes branche sur l'API serveur quand Gestion Club est ouvert via `/gestion`.
- Repli sur `state.teams` lorsque le HTML est ouvert en autonome.

## Validation

- Liste des equipes lue depuis SQLite.
- Detail d'equipe avec conservation du payload source.
- Presence du pont API dans le client complet servi par le serveur.
- Suite automatisee attendue : 84 tests.

## Limites conservees

- Les modifications fines d'equipes restent locales jusqu'a une version dediee.
- Les compteurs joueurs et matchs restent calcules cote client.
- Le module Matchs n'est pas encore migre vers SQL/API.
