# V1.25.4 - Lecture des licencies depuis l'API serveur

## Objectif

Commencer l'allegement du client complet en faisant lire l'ecran Licencies depuis le serveur quand Gestion Club est ouvert via `/gestion`.

## Ajouts

- Indicateur de source dans l'ecran Licencies.
- Lecture de la liste via `/api/state/members?limit=500` en mode serveur.
- Repli automatique sur `state.members` lorsque le client est ouvert en HTML autonome ou si le serveur ne repond pas.
- Chargement du detail complet via `/api/state/members/{id}` avant ouverture d'une fiche.
- Acceptation des sauvegardes completes `V1.25.4`.

## Validation

- Controle du client servi par `/gestion`.
- Controle des routes SQL/API licencies.
- Verification du maintien du mode autonome.
- Suite automatisee attendue : 81 tests.

## Limites conservees

- Les ecritures fines de fiches licencies restent locales jusqu'a la prochaine etape.
- La sauvegarde complete reste le mecanisme volontaire pour creer une revision serveur.
- Les equipes, matchs, comptes et imports ne sont pas encore lus module par module depuis SQL.
