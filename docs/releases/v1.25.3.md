# V1.25.3 - Socle SQL/API des licencies

## Objectif

Demarrer la migration module par module vers un vrai serveur metier. Les licencies deviennent le premier module lisible depuis SQLite par API.

## Livré

- Nouveau dossier de services serveur `server/services/`.
- Service `club_state.py` pour les lectures metier issues de la base club.
- Table SQL `members` creee au demarrage.
- Synchronisation de `members` a chaque depot de sauvegarde complete.
- Migration douce d'une ancienne base serveur : reconstruction de `members` depuis la derniere revision.
- API :
  - `/api/state/summary`
  - `/api/state/members`
  - `/api/state/members/{id}`

## Limite volontaire

Le client complet historique n'utilise pas encore directement ces API pour afficher sa page Licencies. Cette version pose le socle serveur et le verifie par tests.

## Tests ajoutes

- Recherche de licencie par API.
- Lecture de fiche detaillee avec payload source conserve.
- Migration d'une base serveur existante vers la table `members`.
