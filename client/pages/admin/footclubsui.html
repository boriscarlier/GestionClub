Ouvrir une capture du plugin

Dans Footclubs, utiliser « Vers Gestion Club… », puis choisir le fichier JSON ici. Pour une fiche ou un bloc : dans Footclubs UI V0.08.8, ouvrir le Centre de collecte, choisir le contenu, prévisualiser puis créer le fichier de collecte. Chaque capture reste partielle.

Aucune capture ouverte. Aucun accès à Footclubs au démarrage.

Formats acceptés : sélection Gestion Club selected-source/1 (1,5 Mo), liste page-snapshot/1 (5 Mo) et collecte source-capture/1 (1,5 Mo). Les exports FFF Adapter se chargent dans .

Comparer les contacts avec la base du club

1. Contrôler la fiche → 2. Choisir les champs → 3. Sauvegarder → 4. Confirmer et appliquer.

Le numéro personne identifie la personne. Les licences, représentants légaux, adresses, paiements et sanctions restent en consultation. Une fiche locale unique, son nom, sa naissance et son appartenance au club pour la saison sont exigés.

Saison issue de la fiche club enregistrée lorsqu’elle est disponible. Sinon, indiquez explicitement votre saison de travail. L’affiliation vient du Paramétrage du club.

Historique des contacts et annulation

Les 30 dernières opérations sont conservées. Une annulation est bloquée si la fiche a changé depuis. Une sauvegarde de récupération est enregistrée avant chaque application ou annulation.

Vérification sans données réelles

Ce test intégré utilise une fiche fictive en mémoire : comparaison, application simulée, réimport et annulation.

Choisir les rubriques à exporter

La sélection produit une copie partielle distincte, réutilisable dans ce module. Elle ne met pas à jour la base du club. Les rubriques non capturées ne sont pas disponibles.

Les blocs sont conservés tels qu’ils ont été capturés. Vérifie aussi « Autres informations » : cette rubrique peut contenir des données personnelles dont le contexte est incertain. Photos et références de fichiers exclues.

Lecture temporaire, pas de synchronisation. La capture n’est pas stockée dans la base et est effacée à la sortie du module. Aucune donnée absente ne supprime une information locale. Des valeurs non enregistrées côté Footclubs peuvent apparaître dans une capture. Les changements de contacts explicitement confirmés sont journalisés séparément.

Un module du projet, deux lieux d’exécution

1 · Footclubs dans Brave

Interface modernisée par l’extension installée : listes, aperçu, fiche et photo en lecture seule.

2 · Capture choisie

Export manuel de liste ou collecte choisie de texte et tableaux. Les références de documents ne sont pas leurs fichiers originaux.

3 · Gestion Club

Consultation dans le Centre Sources FFF. Comparaison et application explicite des contacts avec sauvegarde et annulation. Les licences restent en consultation.

Ce module HTML ne prouve pas que l’extension est installée et ne commande pas son thème. Les réglages visuels restent dans le menu du plugin existant.

Installer ou reprendre l’extension existante

Sur le poste de test Brave, utiliser le paquet Footclubs UI V0.08.8 pour le Centre de collecte ; les exports de listes V0.08.7.2 restent compatibles. Dans brave://extensions/, charger son dossier décompressé contenant manifest.json, désactiver les anciennes copies puis recharger Footclubs. Ne pas installer plusieurs versions simultanément.

Ouvrir Footclubs ↗

Connexion officielle dans un onglet distinct. La page intermédiaire et les validations FFF sont conservées. Aucun identifiant FFF n’est demandé ici.

Vérification sur le poste utilisateur

Connexion → page intermédiaire → Licences / Liste → filtre → aperçu → fermeture → export JSON → lecture dans Gestion Club. Contrôler aussi le retour à la présentation native en désactivant le plugin.

La consultation de l’exemple peut être testée sur tablette. L’exécution de l’extension est un test distinct sur un navigateur compatible ; elle n’est pas embarquée dans ce HTML.
