Diagnostic & partage — V1.24.5

Paquet serveur V1.24.5

Le paquet ZIP comprend DEMARRER_SERVEUR.cmd : il démarre un dépôt de sauvegardes versionnées sur cet ordinateur, avec des comptes serveur distincts. L’application métier reste enregistrée dans Brave. Dépôt et récupération utilisent vos sauvegardes complètes JSON ; aucune synchronisation automatique.

Après lancement du serveur : Ouvrir les sauvegardes serveur.

Le serveur doit être lancé depuis le paquet extrait. Ce HTML seul ne suffit pas à le démarrer. Les essais sur un autre ordinateur et le déploiement HTTPS restent à préparer.

Ce contrôle lit la base actuelle sans la modifier. Il permet de repérer les problèmes d’identifiants avant une restauration ou un futur transfert.

Ce qui fonctionne aujourd’hui

Les données restent dans ce navigateur. Les sauvegardes JSON permettent un transfert manuel avec remplacement explicite. Les captures Footclubs et le compagnon FFF ne synchronisent pas la base entre dirigeants.
